# 立山BC GPSログ調査・統合（2020-11-25〜2025-12-31）

立山・室堂周辺のBCスキー・スノーボードの**実測GPS軌跡**を1枚の地図に重ね、YAMAPに取り込めるGPXを作るための作業フォルダです。

## 現状（2026-11-05 時点）

- 調査環境のネットワークポリシーにより、yamap.com・yamareco.com などに直接アクセスできませんでした。そのため、**GPXは1件も取得できていません**。
- Web検索で候補記録を11件抽出し、`records.csv` に整理しました。このうち対象期間（11/25以降）に掛かるのは5件で、確認待ちが1件あります。
- 推測した座標や推定滑走ラインは一切作っていません。

## 構成

| パス | 内容 |
|---|---|
| `records.csv` | 候補記録の一覧（URL、日付、記録者、距離、標高差、エリア、期間判定、GPS取得状況と取得不能の理由） |
| `gpx_input/` | 実測GPXの置き場所（ファイル名の先頭を record_id にする） |
| `build.py` | 解析と出力のスクリプト |
| `output/tachiyama_BC_2020_2025.gpx` | 統合GPX（記録ごとに1 trk。GPXが1件以上あるときだけ出力） |
| `output/by_year/` | 年度別GPX |
| `output/single/` | 記録ごとの単一トラックGPX（YAMAPへの取り込み用） |
| `output/tachiyama_BC_map.html` | 統合地図（地理院タイル＋Leaflet。年度別・記録別の色分け、滑走は実線・登りは破線） |
| `output/tachiyama_BC_log_list.xlsx` | 記録一覧、GPS取得不能一覧、区間解析、取り込み時の注意、調査メモ |

## 使い方

```bash
pip install openpyxl
python3 build.py            # 対象期間外（11/25より前）の点は除外
python3 build.py --no-clip  # 期間外の点も残す
```

## 処理内容

- **期間判定**: 各年の 11/25〜12/31（JST）に入る点だけを残します。たとえば11/24〜25の記録なら、25日の部分だけが残ります。
- **登り/滑走の区分**: 60秒窓の鉛直速度と水平速度から自動判定します。座標は変更せず、区分の属性を付けるだけです。時刻のないGPXは「区別不可」になります。
- **重複整理**: 点列が完全に一致するものは除外します。開始時刻が近く、軌跡がほぼ重なるもの（同行者の記録など）は近似重複として残し、統合GPXには代表の1件だけを入れます。
- **実測の扱い**: `<rte>`（計画ルート）は実測ではないので取り込みません。立山周辺の範囲外の点は警告します。

## YAMAPへの取り込みについて（未検証）

YAMAPの最新のGPX取り込み仕様は、この環境から公式ヘルプを閲覧できず、確認できていません。互換性を優先して次の方針にしています。

- GPX 1.1、`trk/trkseg/trkpt`、`ele` と `time`（UTC）を付けて出力します。
- 1ファイルに複数トラックを入れると、最初のトラックしか読まれないアプリが多いため、`output/single/` に1ファイル1トラックの版も出力します。
- 取り込む前にYAMAPのヘルプ（GPXの取り込み、ファイルサイズや点数の上限）を確認してください。
